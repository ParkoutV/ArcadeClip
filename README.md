# ArcadeClip

이 저장소는 [151net/ArcadeClip](https://github.com/151net/ArcadeClip)의 포크입니다.
로컬에서 작업한 인식·미리보기·GPU 분석·스트림 수신 개선을 포함하며,
AMD64/ARM64 겸용 설치 파일은 Windows 아키텍처를 자동으로 판별합니다.
설치 중 Python과 FFmpeg를 각각 내장하거나 호환되는 로컬 설치를 선택할 수 있습니다.
PATH에서 호환되는 도구를 찾으면 로컬 사용을 권장합니다.
빌드 방법과 호환 조건은 [Windows 빌드 안내](docs/develop/WINDOWS.md)를 참고하세요.

## 시작하기

처음 한 번만 하는 준비입니다.

1. 통합 설치 파일(`user-setup.exe`)로 설치하거나 배포 폴더의 `ArcadeClip.exe`를 실행하세요. 폴더 안의 다른 파일도 함께 두세요.
2. **폴더 선택**으로 데이터 폴더를 지정하세요. 곡 자켓 약 100 MB를 이 폴더에 받습니다.
3. **시작하기 →**를 누르고 다운로드가 끝날 때까지 기다리세요. 약 10분이 걸릴 수 있습니다.

다음 실행부터는 같은 폴더의 파일을 다시 씁니다. 앱에서 **도움말** 또는 **F1**을 누르면 설명서가 열립니다.

## 클립 저장하기

순서대로 진행합니다.

1. **영상 열기** — **파일 추가** 또는 **폴더 추가**로 영상을 여세요. 창으로 끌어와도 됩니다. YouTube 구간을 내려받거나 **OBS 스트림 자동 클립**으로 실시간 방송(RTMP/SRT, YouTube 라이브)을 바로 녹화해 열 수도 있습니다.
2. **시간 범위 지정** — 곡을 찾을 **시작**과 **끝**을 정하세요. 영상 전체에서 찾으려면 **전체 구간**을 누르세요.
3. **곡과 글자 위치 지정** — **자켓**·**1P 이름**·**1P 달성률** 영역을 영상 위에 사각형으로 그리세요. 같은 촬영 구도로 저장해 둔 프로필이 있으면 **프로필 선택**에서 고르면 됩니다. 필요에 따라 **GPU 영상 디코딩**, **GPU 이미지 변환**, **디코딩·변환·판독 겹쳐 처리**를 선택하고 **이 구간에서 곡 찾기 →**를 누르면 곡을 찾습니다. 긴 영상은 시간이 오래 걸릴 수 있습니다. 하단 진행 상태를 확인하세요.
4. **클립 확인** — 찾은 클립을 재생해 확인하고, 저장할 클립에 체크하세요.
5. **파일 저장** — **폴더 선택**으로 저장 위치를 고르고, 파일명을 확인한 뒤 저장을 시작하세요.

저장이 끝나면 **선택한 폴더 열기**로 결과를 확인하세요.

## 필요할 때만 하는 편집

아래 A·B·C는 선택 사항입니다. 하지 않아도 클립을 저장할 수 있습니다.

- **A. 곡명·이름·달성률 고치기** — 파일명과 챕터 제목에 쓸 정보입니다. 바꿀 필요가 있을 때 수정하고 **수정 적용**을 누르세요.
- **B. 클립의 시작·끝 조정** — 곡 앞뒤를 더 담으려면 파란 구간의 양끝을 드래그하세요. **클립 시작·끝 일괄 조정**에서 모든 클립에 한 번에 적용할 수도 있습니다.
- **C. 저장 방식 바꾸기** — 기본은 **원본 빠른 복사**입니다. 빠르지만 시작·끝이 조금 달라질 수 있습니다. 경계를 정확히 맞추거나 화질·용량을 조절하려면 **저장 설정**에서 **정확한 구간 자르기**를 고르세요. 저장에 시간이 더 걸립니다.

## YouTube 구간 가져오기 · 실시간 스트림 수신

### YouTube 선택 구간 다운로드
1. **YouTube 링크**에 주소를 붙여넣고 **영상 정보 확인 →**를 누르세요.
2. 슬라이더 양끝을 끌어 받을 구간을 정하세요. 시간축을 누르고 1초 기다리면 미리보기가 나옵니다.
3. **선택 구간 다운로드**를 누르세요. 완료되면 받은 영상이 열립니다.

진행 중인 라이브는 음수 시간을 씁니다. `-30:00`부터 `-00:00`까지는 조회한 최신 지점까지의 마지막 30분입니다. 새 구간은 **정보 새로고침**으로 확인하세요. 일반 영상과 처리가 끝난 지난 라이브는 영상 시작부터의 시간을 씁니다.

### OBS 스트림 · YouTube 라이브 실시간 수신
1. 영상 열기 화면의 **OBS 스트림 자동 클립**에서 **선택지 A · 직접 수신 (RTMP/SRT)** 또는 **선택지 B · YouTube 라이브 자동 감지**를 고르세요.
2. **스트림 자동 수신 시작**(또는 **개별 라이브 녹화 시작**)을 누르면 실시간 방송을 연속 저장합니다.
3. 방송이 끝나거나 **수신 정지 · 시간 선택으로**를 누르면 녹화된 영상이 시간 선택 단계로 열립니다. 미리 저장해 둔 프로필로 클립 추출까지 자동 진행하려면 **수신 후 자동으로 곡 분석 및 클립 저장**에 체크하세요.

## 실행 환경

Windows 10·11 AMD64 또는 Windows 11 ARM64에서 사용하세요.
ARM64에서는 격리된 x64 OCR 런타임을 위해 Windows의 x64 에뮬레이션을 사용합니다.

## 소스에서 실행하기

Python 3.11 이상과 [uv](https://docs.astral.sh/uv/)가 필요합니다. FFmpeg는 `tools/` 폴더 또는 PATH에 두세요.

```sh
uv sync --locked
uv run start.py
```

준비물과 검사 실행은 [개발 환경 준비](docs/develop/SETUP.md)에 있습니다.
